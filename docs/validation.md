整理日期：2026-10-13。此文仅公开验证摘要，不包含源代码、内部调试日志或本地文件路径。

## 最新桌面验证

环境：Windows、Godot 4.7.2、NVIDIA GeForce RTX 4060 Ti、OpenGL 3.3 桌面渲染。

| 检查项 | 结果 | 边界 |
| --- | --- | --- |
| 编辑器后台导入 | 退出码 0 | 不是编辑器窗口人工试玩 |
| 12 项共用规则 | 通过 | 自动检查 |
| 四关配置 / 脚本 / 场景 | 通过 | 各色沙量与总车容量匹配 |
| 四关胜利 / 失败流程 | 通过 | 自动场景测试 |
| 沙子重力与守恒 | 通过 | 下落、斜向滑落、边界、无重叠、各色总量守恒 |
| 四关初始画面 | 已截图 | 桌面引擎视口截图 |
| 综合关实时通关 | 通过 | 自动派车、真实时间推进；实际收集与十车撤离，没有手动增加装载量、强制清沙或跳过离场 |
| 综合关死锁失败 / 新开局 | 通过 | 错误颜色填满车道会失败，新开局恢复十辆车 |
